# QQ 关键词自动回复 App (Android)

手机端运行的 QQ 关键词自动回复机器人。通过 proot 容器在 Android 手机内运行 NapCatQQ，App 作为控制端和管理界面。

## 技术路线

```
┌─────────────────────────────────────────────────────────────┐
│                      Android App (Kotlin)                    │
│                                                              │
│  UI (Compose) ──► Service Layer ──► Data Layer (Room)        │
│                       │                                      │
│                       ▼                                      │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              NapCat 容器层 (proot)                    │    │
│  │  ┌──────────────┐    ┌──────────────────────────┐   │    │
│  │  │  NapCatQQ    │◄──►│  OneBot V11 WS/HTTP API  │   │    │
│  │  │  (Linux)     │    │  (127.0.0.1:3001)        │   │    │
│  │  └──────────────┘    └──────────────────────────┘   │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

## 核心功能

- 连接管理：启动/停止手机内 NapCat 服务，扫码登录 QQ
- 关键词库：exact / contains / regex 匹配，命中回复，未命中静默
- @ 回复：群聊时 @ 提问者
- 图片回复：支持发送图片
- 查询日志：记录每次触发
- AI 人设（Persona）隔离：每个用户的人设私有，带 `ownerUserId` 字段
- 预留 OpenAI 接口层

## 技术栈

- Kotlin + Jetpack Compose
- Room (SQLite)
- Coroutines + Flow
- Hilt
- OkHttp + WebSocket
